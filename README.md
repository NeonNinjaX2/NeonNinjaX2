## 🎮 Hustle Dave

A money-making idle game in [`hustle-dave/index.html`](hustle-dave/index.html). Download it and open it in any browser to play.

- Click **Work** to earn cash, then buy businesses (from a lemonade stand up to a Moon Mall) that earn money every second
- Buy upgrades and lifestyle items. Dave's outfit changes as he gets richer: sneakers, a suit, sunglasses, a top hat, a crown
- Catch golden bills for bonuses, avoid the tax man, and trade DUCK stock
- Earn trophies, then **Retire** to start over with permanent Legacy bonuses
